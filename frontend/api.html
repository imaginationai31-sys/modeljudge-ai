Recommended buyer workflow

1. List releases. Discover available immutable dataset versions.
2. Pin the exact version. Use a specific release such as 0.9.1 for reproducibility.
3. Inspect evidence. Read the manifest, quality, and reviewer-quality endpoints.
4. Download. Request JSONL or CSV using the authenticated endpoint.
5. Verify integrity. Compare downloaded bytes and SHA-256 against the manifest before use.

Integrity & provenance

Release v0.9.1 is immutable.

The manifest records file size and SHA-256 checksums for each release artifact. Dataset provenance and licensing should be reviewed before commercial use.

Security

Never place a buyer API key in public source code, browser JavaScript, URLs, screenshots, notebooks, or logs. Store credentials in a secure server-side secret manager or environment variable.
