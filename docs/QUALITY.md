# Data Quality Plan

ModelJudge AI treats dataset quality as a first-class product requirement.

## MVP controls

- Explicit schema
- Required fields
- One-to-five score bounds
- Preference validation
- Rationale length requirement
- Verification flag

## Next controls

- JSON Schema validation in CI
- Duplicate prompt/response detection
- Missing-field detection
- Distribution checks
- Reviewer agreement statistics
- Calibration tasks
- Outlier review
- Dataset version reports

## Core metrics

- Valid record rate
- Duplicate rate
- Reviewer agreement
- Preference balance
- Average dimension score
- Verified-record rate
- Category and language coverage
