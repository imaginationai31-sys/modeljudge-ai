# ModelJudge AI Dataset Card

## Dataset status

Early prototype. The repository currently contains illustrative sample records only.

## Intended use

The dataset schema is designed for human preference comparison and structured AI-response evaluation research.

## Fields

Each record contains the prompt, two candidate responses, preference, quality scores, preference strength, human rationale, category, language, and verification state.

## Collection

The current sample records are authored examples used to demonstrate the schema and interface. They are **not** production human-generated preference data.

## Quality plan

Future releases will document reviewer instructions, inter-rater agreement, duplicate detection, reviewer calibration, invalid-record handling, and verification rates.

## Privacy

Do not contribute personal information, private conversations, credentials, confidential data, or sensitive personal data.

## Licensing

The dataset license will be specified separately from the software license when production data collection begins. Do not assume that the MIT software license grants rights to future third-party or contributor-provided datasets.
