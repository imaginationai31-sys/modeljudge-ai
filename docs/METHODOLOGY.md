# Evaluation Methodology

## Current MVP

A reviewer compares Response A and Response B for the same prompt.

The reviewer records:

1. Preferred response: A, B, or Tie
2. Accuracy: one to five
3. Relevance: one to five
4. Clarity: one to five
5. Safety: one to five
6. Preference strength: weak, moderate, or strong
7. Short written rationale

## Reviewer guidance

Judge each response against the prompt. Do not choose a response merely because it is longer, more confident, or stylistically similar to your own writing.

Use the rationale to identify the main evidence behind the preference.
