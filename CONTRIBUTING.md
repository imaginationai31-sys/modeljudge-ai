# Contributing to ModelJudge AI

Thanks for helping improve ModelJudge AI.

## Code contributions

Keep changes focused, documented, accessible, and free of secrets. Add or update tests when behavior changes.

## Dataset contributions

Do not submit personal data, private conversations, confidential material, credentials, or data without appropriate rights and provenance.

Dataset changes should explain:

- source/provenance
- applicable license
- collection method
- quality checks
- intended use

## Pull requests

Describe what changed, why it changed, how it was tested, and whether the change affects the dataset schema.
